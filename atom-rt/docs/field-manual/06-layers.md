# 層

USB という言葉が指すものが、層ごとに違います。取り違えると「CDC が壊れた」「NVS が空」「115200 が遅い」が全部別の病気なのに同じ症状に見えます。

## 五つの層

| 層 | 実体 | 現場で触るもの |
|---|---|---|
| 金属 | USB Full Speed。12 Mbps。パケット最大 64 B | ケーブル、データ線のある口 |
| 仮想 COM | Windows が作るバイトのパイプ。USB-Serial-JTAG の CDC | デバイスマネージャの COM。**文字コードは無い** |
| フレーム | `AA 55` + type + len + payload + CRC | `usb_proto.hpp`。HELLO の ver |
| デーモン | `lab_debug.py` が COM を専有し、JSON に落とす | 起動・再起動。DTR |
| Hub | Socket.IO :8794。ブラウザはここだけ見る | `/atom-bench`、`/m5-telemetry` |

ブラウザは ATOM の COM を開きません。Hub が落ちてもボードは 20 Hz で回り続けます。Python が落ちると COM が空き、次のプロセスが HELLO を取ります。

## CDC とは

CDC は USB の使い方の名前で、「このデバイスはモデムやシリアルだ」と OS に言います。中身は RS-232 ではありません。ボーレート設定はドライバが受け取るだけで、ATOM 側のビットタイミングは変わりません。

Arduino コアでは `Serial` がこのパイプです。Lite の `rt-usb` は **HWCDC**（USB-Serial-JTAG）です。TinyUSB デバイススタックの API は使えません。

同じ USB コネクタでダウンロードモードにも入ります。書き込み中はアプリの CDC ではありません。緑 LED で区別します。

## 同時に送れるか

ホスト→デバイスとデバイス→ホストは同時に流れます。Ping を送りながらテレメトリが来るのは正常です。

制約は **出口が一本**なことです。Core 0 が `Serial.write` するとき、64 バイトずつ USB に載ります。TX バッファ（ver 14 は 4096）を超えると待ちます。待っているあいだにフラッシュキャッシュが止まっていると、コードもデータも進みません。

## 20 Hz はなぜ無事か

テレメトリは 50 ms に 1 回、payload 316 + 枠 7 バイトです。USB FS から見ると小さいです。Core 1 が I2C しているあいだ、Core 0 は直前のスナップショットをコピーして送るだけです。フラッシュは触りません。

校正マップの MapGet は、送出中にテレメトリを止めます。チャンクも小さいので、同じパイプでも通ります。

## なぜ NVS 一覧がパイプを殺すか

`nvs_list` はキーの名前だけでなく **値** も送ります。`mx0` / `my0` は数百バイトです。しかも読み出しのたびにフラッシュキャッシュが止まります。その間も 20 Hz は送ろうとします。

よくある並び:

1. イベントに「NVS 読み取り開始」
2. 1 秒前後で HELLO（COM が落ちて Python が開き直した）
3. Windows 側に `ClearCommError` が出ることがある
4. Hub の NVS は未読取のまま。プロファイル RAM は生きていることがある

ver 14 は待ちと間隔を足しましたが、**値を載せる限り根本ではありません。** 次にやるなら一覧はメタデータだけ、値はキー指定、ダンプ中はテレメトリ停止、です。MapChunk がその成功例です。

NVS タブは開いているあいだ 1 回だけ `nvs_list` します。再接続では撃ち直しません。プロファイル保存の直後にも全文は流しません。値つきダンプ自体はまだ重いので、「ボードから読む」も校正済みだと落ちることがあります。

## やってよい送り方

| データ | 今のやり方 | メモ |
|---|---|---|
| 20 Hz スナップショット | 常時 | 問題にならない大きさ |
| 関節プロファイル | ProfPut / ProfGet の 1 フレーム | 80 バイト級 |
| 校正マップ | MapChunk。テレメトリ停止 | 通る |
| NVS キー一覧 | まだ値つき全文 | 校正済みだと落ちやすい |
| 巨大 JSON を COM に印字 | しない | バイナリフレーム以外は同期を壊す |
