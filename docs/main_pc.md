## 実機で分かったこと

腰の変換は、学習と同じである。ガウス分布の平均に 0.25 rad を掛け、直立からの目標にする。出力は ±1 に切っていない。サーボへ届くのは角度だけで、学習の Kp=80、Kd=2 は書かない。腰は前進 0 の包絡で、その目標をサーボへ出す前に抑える。

大きな目標は、この重みが直立の観測に対して出す値である。書き出し時に Torch と腰の式を照合した結果は、`core-rt/src/policy_weights.hpp` の先頭コメントにある。実機の take では、かかとピッチの計測が学習の平均から外れていて、次の周期ではその出力が「直前の出力」として戻った。それで、コメントの直立よりさらに振れた。

吊り下げで足裏がほぼ 0 だったことは、この大きな目標の原因ではない。足裏だけを学習の平均に戻しても、ひざとかかとピッチの目標は大きいまま残る。足裏をシミュと比べるのは、足が体重を受けているときだけ。手順は [sim_to_real.md](sim_to_real.md)。
