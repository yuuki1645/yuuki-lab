# 実機とシミュを交互に見る

Isaac Lab の学習は、現実の等身大ロボットを動かすところまで進める。現状の機体は脚と腰のカゴで、吊りベルトで落下を受けられる。学習だけを長く続けず、実機で取るデータとシミュの再生を交互に繰り返す。分布の違い、センサの解釈の違い、プログラムのバグを、歩行の前に見つける。

自由な歩行は、このページの確認が合うまで行わない。吊りベルトは、データを取るあいだも外さない。

角度のプラスは [joint_angles.md](joint_angles.md)。実機のセンサの経路は [robot_control.md](robot_control.md)。学習の現行は [now.md](now.md)。

## 比べる場所

実機は Hub の実機テレメトリ（`:8794`）。シミュの再生は同じ画面へ、橋（`:8795`）から出す。両方を同時にはつながない。画面の度は同じ規則にする。RDS51150 の直立は 135°、ひざとかかとピッチの直立は 0°。

方策が見る量のうち、実機のセンサで確認できるのは次のとおり。

| 量 | 直立で期待すること |
|---|---|
| 10 関節の角度 | 画面の直立。プラスの向きは joint_angles.md |
| IMU の重力 | 体の前が +x、左が +y、上が +z。直立なら z が約 −1 で、x と y は 0 に近い |
| 角速度 | 止まっていれば 0 に近い |
| 足裏 8 隅の kg | 足が体重を受けているときだけ。8 隅の合計は、足の下の秤と比べる |

位相と、方策が直前に出した目標は、センサが合ったあとに見る。ソフトウェアの値で、秤や IMU の代わりにはしない。

シミュの足裏合計は、URDF の質量に近い。実機の合計をその質量の数字に合わせない。吊っていて足が体重を受けていないあいだは、足裏をシミュと比べない。

## 1. 直立

吊りベルトを付けたまま、実機を直立の指令で保持する。シミュは再生 1 体、スティック中央（前進の指令 0）で、同じ画面に出す。

まず関節角と IMU、角速度。左右でプラスの意味が逆になっていないか、135° と 0° を取り違えていないかを見る。

次に、足が床について体重の大部分を受けた状態で足裏を見る。ベルトは弛ませて落下だけを受ける。8 隅の合計を秤と比べ、左右と前後の偏りをシミュの同じ姿勢と比べる。

## 2. 直立の次

歩行には入らない。同じ小さな姿勢を、シミュの再生と実機の両方で作り、1 種類ずつ比べる。ベルトは付けたまま。角度は人間の可動の内側で、ゆっくり動かす。

1. 関節を 1 種類だけ、直立から少し動かす。股ロールは外側、股ピッチは前、ひざは後ろ、かかとピッチはつま先を上げる、かかとロールは内側が下がる、と画面のプラスが実機でもその向きになるかを見る。
2. 両足を床につけたまま、股ロールで左右へ少し体重を移す。荷重が増える足が、動かした側と一致するかを見る。
3. 両ひざを少し曲げる。関節角と、IMU の前後の傾きを見る。

ここまでが合ってから、方策を実機の直立保持に使う。スイッチは USB `0x92` で、起動時は切れている。実機テレメトリの「方策」ボタンが同じコマンドを、前進 0 で出す。最初の前進指令は 0、ベルトは付けたまま。入れる前に、画面の重力 z が約 −1 であることを見る。軸が違うときは `core-rt/src/bmi270_waist.cpp` の表だけを直す。方策の目標が、すでに確認した直立から大きく外れないかを見る。

一歩を踏み出す確認は、その後である。ベルトが落下を受けられる状態で、シミュと同じ小さな前進指令を短時間だけ出す。
